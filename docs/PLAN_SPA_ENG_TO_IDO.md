# Plan: Spanish → Ido, English → Ido

Status: draft, 2026-11-08. Direction: into Ido only; the reverse is a later project.

## Starting point

- **Ido side is ready.** `apertium-ido` has a full monodix (~91k entries) with generation; any new pair only needs analysis on the source side plus a bidix and transfer rules.
- **Source side exists upstream.** Apertium has mature `apertium-spa` and `apertium-eng` monodixes (analysers, taggers), and released pairs `apertium-eo-es` (es→eo) and `apertium-eo-en` (en→eo). A local checkout of `apertium-eng-spa` is in `research/apertium-en-es/`.
- **Words are available.** Of 55,519 Ido pages on io.wiktionary, 43,556 have an `{{en}}` line and 42,930 an `{{es}}` line (counted on the local dump). The extractor already parses these pages; today it keeps only `{{eo}}`.

## Phase 0: pivot through Esperanto (days)

Chain the existing pairs: `spa → epo` (apertium-eo-es) → `epo → ido` (ours), same for English.

- Add `spa-ido` and `eng-ido` modes to tradukilo that pipe one pair into the other; a direction selector in the UI.
- Cost: errors add up (two systems, two sets of `*` unknowns), and the Esperanto step loses nothing Ido needs, so quality is roughly that of the weaker pair.
- Purpose: something usable now, plus a baseline score for Phase 2 to beat.

## Phase 1: English/Spanish glosses in vortaro (days)

**Spanish: done (2026-11-09).** extractor #205 (`{{es}}` lines → `spanish_words`), vortaro #167–#171: *Esperanto | Español* switch, `/io-es/` and `/es-io/`, accent-insensitive search; 10,854 of 37,858 entries. English: not started.

The cheapest answer to the r/Ido request.

- Extractor: keep `{{en}}` and `{{es}}` lines from io.wiktionary, as it does for `{{eo}}`. Make the target language a parameter instead of hard-coding `eo`.
- vortaro: show EN/ES under each Ido entry; optional search by English/Spanish word.
- Same rule as today: fixes go into Wiktionary, never by hand into data files.

## Phase 2: direct pairs `apertium-spa-ido`, `apertium-eng-ido` (weeks per pair)

1. **Bidix** generated by the extractor: io.wiktionary `{{es}}`/`{{en}}` lines as the main source, plus en/es Wiktionary, Wikidata labels, and the existing epo pairs as a pivot for words still missing (lower confidence).
2. **Analysis**: build against upstream `apertium-spa` / `apertium-eng`, trimmed to the bidix as with epo.
3. **Transfer rules** (hand-written, as for ido-epo). Main work per language:
   - **Spanish → Ido**: drop gender agreement (Ido adjectives are invariable); articles el/la/los/las → la; contractions al/del; clitic pronouns before the verb (lo veo → me vidas lu); reflexive `se`; ser/estar → esar; tense/mood collapse to Ido `-as/-is/-os/-us`; subjunctive → `-ez` or `-us`.
   - **English → Ido**: no article for a/an; do-support (do you know → ka tu savas); auxiliaries will/would/have+participle → `-os/-us/-is`, progressive → simple tense; possessive `'s` → `di`; phrasal verbs (give up, look for) as multiwords; noun-noun compounds (book shop → librerio / butiko di libri).
4. **Lexical selection** (`.lrx`): English is highly ambiguous (run, set, get); start with the most frequent sense, add rules from corpus errors.

## Evaluation

- Gold sets like the existing `ido_epo_tatoeba.tsv`: Tatoeba sentence pairs eng–ido and spa–ido, built the same way as `build_gold_epo_ido_tatoeba.py`.
- chrF and coverage via `eval_translation.py`; regression tests via `apertium-regtest`, as for ido-epo.
- Phase 2 ships only when it beats the Phase 0 pivot on the gold set.

## Order and rough effort

| Step | Effort | Gives |
|---|---|---|
| 0. Pivot modes in tradukilo | 1–2 days | ES/EN→Ido usable now, baseline |
| 1. EN/ES glosses in vortaro | 2–3 days | answer to r/Ido, data for step 2 |
| 2a. spa-ido bidix + core rules | 2–3 weeks | Spanish first: closer to Ido, regular morphology |
| 2b. eng-ido | 3–4 weeks | harder: ambiguity, word order, auxiliaries |

## Open questions

- Hosting: the tradukilo server builds pairs on EC2; two more pairs plus upstream spa/eng monodixes add build time and memory. Check instance size before Phase 2.
- Spanish first or English first? Spanish is easier; English has more users.
- License: upstream Apertium data is GPL; our pairs would be GPL too (already the case for ido-epo).
