IdoEnglishEsperanto

About the Translator

This translator converts text between Ido and Esperanto in both directions, using the rule-based Apertium machine translation engine. Because translation is rule-based rather than statistical, results are predictable and every word can be traced back to a dictionary entry.

Features

  • Two-way translation (Ido ↔ Esperanto)
  • Morphological analysis of words
  • Open source and free to use

Data and sources

The dictionaries and rules are open source. The dictionary is built from Wiktionary and Wikipedia data, and the same data powers the Ido–Esperanto Dictionary (Vortaro).
