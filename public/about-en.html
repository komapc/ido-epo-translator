IdoEnglishEsperanto

About the Translator

This translator converts text between Ido and Esperanto in both directions. It has two engines: the rule-based Apertium engine (the default), whose results are predictable and where every word can be traced back to a dictionary entry, and a neural engine (beta) that runs in your browser.

Neural translation (beta)

The neural engine is NLLB-200 (600M parameters) fine-tuned for Ido on Ido–Esperanto sentence pairs. It runs entirely in your browser after a one-time download (about 610 MB to translate from Ido, about 990 MB to translate into Ido), which the browser keeps for later visits, so the text you translate is never sent to a server. If you would rather not download it, you can run the same model on our server instead: your text is then sent to it for translation and is not stored or logged. It can also translate between Ido and English, Spanish, French or German; these pairs are experimental.

  • Quality: on a held-out test set of 1,000 sentences it scores chrF 73, against 65 for the rule-based engine.
  • It is usually more fluent, but it can change or invent words, so check names, numbers and rare terms.
  • It translates one sentence at a time and works best on everyday sentences.
  • The browser build has a reduced vocabulary and 8-bit weights; the model is licensed CC BY-NC 4.0 (non-commercial).

Switch the engine under the input box with Neural β. There is also a standalone demo.

Features

  • Two-way translation (Ido ↔ Esperanto)
  • Rule-based and neural (in-browser) engines
  • Morphological analysis of words
  • Open source and free to use

Data and sources

The dictionaries and rules are open source. The dictionary is built from Wiktionary and Wikipedia data, and the same data powers the Ido–Esperanto Dictionary (Vortaro).
